# Python Calculator App

A simple command-line calculator built with Python that performs basic arithmetic operations based on user input.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero error handling
* User-friendly command-line interface

## Technologies Used

* Python

## Learning Concepts

* Variables
* User Input
* Conditional Statements (if/elif/else)
* Arithmetic Operations
* Error Handling
* Formatted Output

## How to Run

1. Run the Python script.
2. Enter two numbers.
3. Choose an operator (+, -, *, /).
4. View the calculated result.
